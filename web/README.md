# 镜序 FRAMEFLOW · 前端（web/）

Vue 3 + Vite。安装、启动与整体说明见根目录 [`README.md`](../README.md)。

```bash
npm ci
npm run dev      # 开发模式：5173 端口，/api 与 /files 代理到 8000
npm run build    # 生产构建：产物在 dist/，由后端同源伺服
npm run check    # 文件引用、组件、模板变量与接口封装检查
npm run test     # 前端逻辑回归，不调用模型
npm run format   # 统一源代码格式
npm run format:check # 校验代码格式
npm run browser:install # 首次安装测试浏览器
npm run test:browser # 完整浏览器验收，先在另一个终端启动 dev
```

代码职责见 [代码整理说明](../docs/code-organization.md)。页面与素材样式在独立 scoped CSS 中，视频参数面板与描述输入框分开维护。

视频输入框支持 `@` 搜索当前视频已连接的角色、道具、场景和上传图片。点击结果或用上下键、Enter 选择，只插入引用标签；新增素材需要通过「参考素材」入口或画布连线。素材必须先准备好，并遵守当前工作流的参考图上限。输入区上方显示带序号的紧凑缩略图，鼠标停留时浮出放大预览，移开后关闭。序号与实际 Picture 顺序一致，保存、复制创作及编辑器内部复制粘贴都保留素材身份。断开引用的素材会标红并阻止提交，直到重新连接或删除该标签。

标签保存的是素材种类和名称，生成时由后端按实际参考槽位解析：AI 编排收到名称与对应编号，英文直出收到模型标签。调整素材顺序不需要手改提示词编号。未生成的视频卡及镜头序列不把参考图片当作成片封面。

界面支持白天 / 夜间模式：点击左侧底部的太阳或月亮图标即可切换。收起侧栏时仍显示图标；手机上先打开顶部导航菜单。选择保存在当前浏览器，刷新和重新打开后保留。画布、创作输入框、素材工坊、预览及服务设置同步切换，原素材和视频颜色不变。

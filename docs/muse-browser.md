# Muse 画布接入（试用）

此接入通过 Muse 的公开网页提交任务，不使用未公开接口，也不复制其他 Chrome 窗口的 Cookie 或密码。Muse 的真实视频生成能力、额度及素材支持由登录账号提供。

## 首次连接

1. 刷新镜序，打开「服务设置 → 视频生成 → Muse」。
2. 点击「打开 Muse 面板」。Muse 默认在后台启动，官方页面显示在镜序内，无需挂着独立浏览器窗口。
3. 在面板内完成官方登录，选择或新建一个用于画布生成的旁聊，例如「镜序画布」。保持消息输入框为空。
4. 点击面板右上角「使用当前聊天」，面板收起。看到「当前聊天已连接 · 后台运行」后保存设置。
5. 在画布填写视频描述，可以连接图片素材，也可以仅用文字。点击生成，完成后视频会下载、校验并回填该节点的版本记录，可继续预览和导出。

登录保存在本机项目的专用浏览器配置中，此目录已忽略，不进入 Git。后台和官方登录窗口使用同一浏览器的同一份配置，不复制其他浏览器的 Cookie。关闭 Muse 面板或服务设置不关闭后台浏览器；画布生成和自动下载继续运行。后端重启后重新打开面板、确认要使用的聊天；登录未过期时无需重新认证，过期时在面板内完成官方登录。

面板提供官方网页的实时预览，支持点击、滚动、普通按键、中文输入法和粘贴，登录弹出的网页也显示在面板中。它用于登录和选聊；创作素材仍由画布上传。截图和输入文字只在本机传递，不写入诊断日志或任务记录。面板收起后停止截图轮询，生成不会依赖面板是否可见。

「使用当前聊天」只在 Muse 面板提供，服务设置显示连接状态并保留「打开 Muse 面板」入口。已连接时可直接回到画布生成，切换聊天时再打开面板。服务设置仍负责生成服务选择和等待时长。

面板操作时按约 160 毫秒的间隔安排预览更新，实际速度取决于后台截图耗时；空闲时降至每秒一次，生成期间降低频率，页面隐藏或面板收起时停止预览。截图请求保持单个在途。连续文字和同位置、同方向的滚动会合并，完整保留文字与滚动距离；点击、退格等按键保留操作顺序。连续操作中也会更新预览，确认聊天或切换运行方式前等待已接受的输入完成。

任何手动页面操作都会取消当前聊天绑定，因为 Muse 可以在地址不变时切换旁聊。选好聊天后再次点击「使用当前聊天」。视频生成期间不能操作、切换聊天、改变页面尺寸或切换运行方式，避免干扰自动提交和下载。面板关闭后不会自动重发任何任务。

若官方认证方式无法在后台页面完成，可主动点击「登录遇到问题？使用官方窗口」。这是显式备用入口，正常生成不会调用。完成登录后点击「返回项目面板」，重新确认旁聊并使用当前聊天；切换运行方式会先关闭项目自己的浏览器，再用同一份配置后台启动，不操作其他浏览器窗口。

## 当前范围

- 每次生成一个视频，画布队列按镜头顺序串行执行；可重复创作并保留历史版本。
- 描述直接交给 Muse 编排，无需配置额外文本模型。
- 最多提交九张图片和三个视频附件。上传入口会核对文件类型和多选能力；入口不支持所选素材时停止发送，不丢弃素材继续生成。
- 角色和道具优先使用现有设定图作为参考，也支持仅保存设定图、没有单张形象图的素材。描述中的参考编号与实际上传顺序保持一致。
- 画布中已连接的成功视频、上传的视频都进入 `@` 列表。视频引用保存来源节点身份，避免同名视频串片；选择原本仅提供前情的视频时，自动改为视频附件参考。可预览来源、固定历史版本或指定参考范围。
- 视频参考默认上传整段成片；从结尾续拍上传选定结尾片段，要求 Muse 接续动作。来源先核对作品归属、成功版本和内容指纹，再生成独立缓存；不会把来源视频变成一张缩略图，也不使用 H3 的帧批次裁切规则。
- 可选择画面比例和 480P/720P（或服务默认），计划时长沿用画布的 1–15 秒范围。这些选项作为明确生成要求发送给 Muse，要求不支持时说明实际规格；不是已经验证的原生参数 API。实际成片时长、尺寸仍从下载文件读取。
- 暂不支持锁定首尾帧、随机种子和保证精确输出规格。Muse 续拍是基于视频附件的接续创作要求，不保证逐帧衔接。关闭音频时本地成片会移除音轨。
- Muse 需要在对应成片回复中返回本次唯一任务编号。支持完整 MP4 文件名，也支持“任务编号 + 视频已完成/可下载”的回复；原请求、未完成或失败回复、其他任务结果不会自动导入。

## 失败与恢复

遇到登录失效、网页控件变化、需账号确认、超时或下载链接不匹配，会停在可检查的状态，显示处理建议。查看专用旁聊即可继续完成 Muse 端操作，成片也可通过镜序现有的「上传视频」功能导入。

下载完成前应保持镜序后端服务运行。Muse 面板可以收起。后台浏览器或服务在下载期间退出时，程序释放等待中的下载并保留原提交记录，提示重新连接后取回原成片，不会重复生成。

提交前记录 `seg_<job>.muse.json`，包含任务编号、聊天地址、完整草稿、素材与参数指纹以及提交阶段。发送使用输入框所在区域的发送按钮，包括只有箭头图标的按钮；找不到唯一可用按钮时保留内容并提示处理，不通过回车猜测发送。

如果内容仍留在 Muse 输入框，可以在画布对同一描述、素材和参数再次点击生成。程序只接受与提交记录完整匹配的自有草稿，继续使用原任务编号及已上传的图片，并同步两次画布尝试的提交记录。重新连接时也允许保留这类草稿。旧版留下的草稿会核对原画布记录后恢复。其他草稿、已改动的任务、已经出现在聊天中的任务以及已完成的提交记录会受到保护，不会覆盖或重复发送。

如果输入框已清空或服务中断发生在发送期间，请先检查原旁聊结果；不会在启动时自动重发。成片可以手动下载后上传到画布。

Muse 已出片而画布仍在等待时，点击该视频输入框下方的「取回 Muse 成片」。重启服务后，如果原提交记录保存了独立的 Muse 聊天地址，取回会复用本机登录，在后台重新打开并绑定原聊天；登录失效时需在面板完成登录。原记录只有网站首页地址时，需先在 Muse 面板打开原聊天并点击「使用当前聊天」，避免猜测旁聊。取回沿用原提交记录、候选文件和画布版本，不上传参考图，不发送提示词，也不会创建新生成任务。结果会校验后回填，并记录实际视频时长。

成片文件名可以出现在视频上方或相邻回复中；正文只返回唯一任务编号及视频完成状态时，也关联该回复的成片卡片，必要时打开成片窗口并使用其中的下载按钮。重复出现的同一视频链接会合并，不会因为播放器与下载链接共用同一地址而误判为多个结果。多个同编号成片或不明确的下载入口会停止取回并提示检查。

成片旁的下载图标也支持直接取回：先悬停对应成片，识别该回复中的下载按钮或下载提示，再下载文件。回复将文件名拆成多个文本片段时仍按完整文件名匹配。

成片识别覆盖公开的网页组件、CSS 缩略图和深层嵌套的回复。下载按钮没有文字时，仅识别对应回复中的向下箭头与托盘图标，不按屏幕位置猜测按钮。下载可以来自当前页面或该按钮打开的窗口；其他标签页的下载不会被回填到本次任务。浏览器返回随机文件名时，任务仍通过对应回复和本次下载事件关联，自动保存到该画布版本的目标文件。

若自动取回仍失败，可在 Muse 下载原 MP4，再点击画布中的「导入已下载成片」。只接受原任务编号对应的文件名（也兼容浏览器自动添加的 `(1)` 等副本后缀），本地校验通过后回填原版本，并读取实际时长、尺寸和音轨；无需重新连接 Muse，也不会重新生成。导入文件最大 100MB，网页或损坏文件不会被标为成功。

自动取回的成片进入项目内的临时目录，校验并发布到作品后删除临时目录，不再另存一份到 `Downloads/Muse`。浏览器下载缓存位于项目的 `.local/muse-download-cache`，完成转存后清理对应的原始下载。手动下载仍另存到 `Downloads/Muse`，为 MP4 补齐扩展名，同名文件加副本编号；关闭浏览器后仍保留。服务设置显示手动保存目录、最近保存的文件和另存失败提示。导入前若 Muse 没有使用约定文件名，请确认对应成片后，将文件改为原任务编号的 MP4 名称。视频参考和续拍不自动继承来源的制作提示词，只有“仅文字前情”连线提供旧描述。

## 运行依赖与验证

需要 Node.js 和 `web` 的 Playwright 依赖（`npm ci --prefix web`）。Windows 优先使用已安装的 Edge，配置位于 `.local/muse-browser-edge/`，避开本机 Chrome 的已知下载崩溃；其他环境使用已安装的 Playwright 配套 Chromium（`npm run browser:install --prefix web`，配置 `.local/muse-browser-chromium/`），未安装时使用 Chrome 及原 `.local/muse-browser/` 配置。切换浏览器首次需重新登录，原 Chrome 配置保留。窗口退出、页面崩溃和服务关闭记录到 `.local/muse-browser-events.log`，不记录提示词或账号凭据。点击「打开 Muse 面板」才启动后台浏览器；独立官方登录窗口仅由备用入口显式打开。

后台模式已通过拦截全部网络的浏览器验证：默认无窗口启动、配置复用、面板关闭后继续生成、中文输入和粘贴文字、登录网页弹出页、过期预览拒绝、草稿保护以及生成时禁止修改聊天。当前机器也已在真实账号验证后台重连原聊天、自动下载既有成片、校验及回填画布；该验证未重新发起生成任务。

```sh
python -m unittest dev.api.test_muse -v
npm run test --prefix web
npm run test:browser:muse --prefix web
```

浏览器测试拦截全部网络，以模拟页面验证流程，不访问真实账号，也不消耗生成额度。

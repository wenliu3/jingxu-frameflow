# 视频创作画布

进入作品的「创作画布」，在无限画布上引用素材并创作视频。每一镜只有一张视频卡，描述与生成结果合在一起。编辑画布不需要启动 ComfyUI，也不调用任何模型。

作品工作区的素材工坊、创作画布和生成记录共用顶栏与侧栏，支持白天和夜间主题。点击侧栏底部的太阳 / 月亮图标切换，浏览器会保留选择。素材编辑、预览和生成历史弹窗继承同一主题；各页分别记住本次浏览的滚动位置，记录详情会自动定位。手机尺寸下可通过顶栏按钮展开导航侧栏。

## 编排

- 左侧「素材库」读取本作品的角色、场景、道具和其他图片。点击素材即可放入画布；选中视频卡时点击素材，会自动连入当前视频。输入框显示带序号的紧凑缩略图，悬停放大、移开收起，支持逐项断开引用。输入 `@` 只列出当前视频已连接的图片素材，选择后插入带素材身份的标签；断开后标签标红并阻止提交。未生成的视频预览保持为空。
- 点击节点右侧的输出圆点，再点击目标节点左侧的输入圆点，即可连线。素材和便签可以连接视频；视频可以连接下一镜，并选择文字前情、视频参考或从结尾续拍。不能重复连接，也不能形成循环。
- 拖动节点标题栏移动节点，拖动空白区域平移画布，滚轮缩放。「显示全部节点」适应全局，小地图可以点击定位。
- 打开作品默认选中一个视频并在该视频卡正下方显示输入框。点击视频可切换创作对象，双击预览可居中查看。点击画布左侧或镜头序列中的加号新增视频，双击空白不新增。输入框与视频卡中心对齐，随节点移动、画布平移和缩放更新位置；选中时会把视频卡和输入框一起移入视野。点击画布空白处可关闭输入框与参数面板，已填写内容和设置保留；点击输入框内的其他位置仅收起参数面板。拖动画布不会关闭窗口；队列和素材设置只在需要时打开。
- 选中视频，在底部直接填写画面描述，点击参数摘要打开生成设置：Auto 或六种画幅、480P/720P/自定义像素预算、4–15 秒自定义时长、音频开关、1/2/4 个候选。新视频默认 720P、5 秒；旧画布沿用原像素预算。高级设置支持随机种子和精确成片时长。运镜菜单可追加描述，Ctrl+Enter 可提交当前视频。便签和上一镜的描述可作为 AI 编排上下文。Ref2VA 最多接入三个视觉视频来源，其中只能有一个续拍起点；英文直出跳过文本编排，仍可使用真实视觉参考。来源版本、范围和指纹在提交前固定，见 [视频参考与续拍](video-continuation-plan.md)。
- 「更多画布操作」中的「导入生成记录」会读取现有视频的边车记录，还原素材与分镜关系。缺少边车记录的旧视频也会成为可播放、可编辑的视频创作卡；备份和操作说明也收在此菜单。
- 移除节点不会删除素材或已生成的视频文件。复制分镜会保留它的素材输入；撤销和重做只作用于画布编辑。

快捷键：`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Delete` 移除选中的节点或连线，`Esc` 取消连线并收起展开视图。输入框中的快捷键保留浏览器默认行为。

`F` 显示全部节点，`Ctrl+D` 复制节点。底部「镜头序列」默认收起，展开后按镜头连线拓扑排序，未连接的镜头保持创建顺序；它是镜头导航，不是可裁剪时间轴。

首页模板会建立三镜结构。顶部「剧本建镜」也能把分段镜头描述转成节点：每镜之间空一行，单镜最多 1000 字，每次最多 30 镜。这些操作不调用模型；选中分镜时建镜会复用它的参考图连接。

画布支持拖入或上传 PNG、JPG、WebP 参考图，每次最多 8 张、每张不超过 15MB。图片存入作品素材库并创建节点；选中视频时上传会同时引用到当前视频。

## 队列与版本

点击输入框的生成箭头会检查描述、参考图和服务配置，通过后直接入队。批量生成会先显示逐镜检查面板。只有检查通过的镜头可入队，按序串行提交。排队和生成中的镜头暂时不能修改描述、参数或输入连接。

暂停只影响尚未提交的镜头，当前任务继续完成。任务失败或保存失败时暂停队列。关闭页面后未提交的镜头暂停，重新进入作品需要点击「继续队列」；已提交任务恢复轮询。队列保存在画布文件中，提交模型请求前确认保存。重新生成会在同一张视频卡内追加版本，成功版本继续保留。多个候选使用不同种子串行执行，显示完成进度；部分候选失败时保留成功文件和失败记录。卡片底部可以切换版本与下载，输入框的版本菜单可以回填历史描述与参数。「对比候选」并排播放最多四个成功版本，可选用于成片。导入生成记录时，同次生成的候选合为一张卡，保留自定义时长与参数。旧画布打开时自动合并原分镜和视频输出节点，文件保留原位。

## 备份与成片

更多菜单支持导出和导入 JSON 画布备份。导入追加节点、重新编号并校验图结构；不会恢复其他作品的生成任务、输出文件或版本号。导入后请重新核对素材引用。

「导出成片」默认采用卡片当前选中的成功版本，左侧按镜头序列核对，点击镜头可在右侧播放预览；只有多个成功版本时才显示版本选择，也可恢复画布选用。顶部显示镜头数与总时长，缺少实际时长时标为估算；未完成镜头提前提示并跳过，序号保留原镜头顺序。镜头列表独立滚动，底部导出按钮始终可见，手机下设置与镜头区整体滚动。导出面板中的版本选择只用于本次成片，不修改画布当前版本。支持 1280×720 横屏、720×1280 竖屏和 720×720 方形，按比例适配并补边，统一为 24fps，保留音轨，无声片段补静音。输出尺寸是本地合并尺寸，不表示模型原生生成分辨率。原视频不覆盖，每次成片写入 `outputs/<task_id>/export/canvas_<job_id>.mp4`。

导出后台执行，界面显示逐镜处理进度，完成后提供下载。浏览器保留任务编号以便刷新后继续查询；后端重启会丢失导出任务状态，可在本地 export 目录查找已完成成片。

## 保存

新建作品页与创作画布使用统一主题。可以填写作品名称后，从剧本助手、手动添加素材或空白画布开始。没有素材时显示起步入口；添加后只显示有内容的分类，并提供进入创作画布的按钮。仅打开助手或素材类型选择不会创建作品，实际添加素材或创建画布时才保存草稿。无需先启动 ComfyUI 即可整理素材和分镜。

作品库与回收站也使用同一套主题。作品卡片显示真实画面素材作为封面，以及素材、分镜和本地视频数量；分镜数量优先取已保存的节点画布，没有画布时兼容旧分镜与分块流程。草稿、素材准备和分镜编排归入「准备中」，实际有视频的作品显示「已有视频」。搜索与状态筛选可以组合使用。列表接口直接提供精简摘要，画布文件未变化时复用解析结果，不为每张卡片额外请求完整作品或视频详情。

画布自动保存到 `outputs/<task_id>/workflow.json`，包含节点、连线、位置、视口和生成任务编号。采用临时文件替换方式写入；多个页面编辑同一作品时用版本号检查，旧页面不能覆盖新内容。

保存失败时保留浏览器暂存并显示错误，可重试或导出 JSON 备份。刷新页面会恢复当前作品和创作画布。作品移动到回收站时，画布文件会随作品一起移动。

## 生成视频

只有主动点击生成箭头、Ctrl+Enter 或确认批量队列后，才会调用模型。打开作品、编辑、上传和合并旧画布不会提交生成。仍使用项目现有的 `/compose`、`/segment/video` 与状态查询接口，能力接口用于检查后端是否已支持新版参数。I2V 和外接 API 接受一张首帧图片；Ref2VA 最多九张参考图片、三个视觉视频来源，续拍起点最多一个。ComfyUI 会将所选画幅、尺寸和种子写入 H3 工作流，首尾帧适配相同尺寸；音频关闭时输出不含音轨。

480P/720P 将画面按比例放入对应的 SD/HD 尺寸范围，超宽画幅保留长边上限（21:9 的 720P 输出为 1280×548），尺寸取偶数。H3 原生尺寸对齐 32 像素网格，下载后适配为输出尺寸；因此输出规格不表示视觉质量保证。自定义模式下，服务设置的「默认分辨率」作为像素预算；明确选择数值只覆盖当前视频。MP 不等同于固定的 720p 或 1080p。外接视频 API 当前协议不接收画幅、分辨率、时长或种子，所以相应控制不可用，时长仅用于提示词的计划节奏；多候选和音轨移除仍可用。

H3 按 24fps、5+17n 帧生成，精确时长默认开启：下载后裁掉多余尾帧，或补齐少量尾帧和音轨，达到所选时长（精度为一帧）。关闭精确控制则保留模型实际时长。生成记录保存每个候选的参数、种子，以及转换后测量的尺寸、时长和音轨状态。视频先在临时目录处理，完整成功后发布，失败不会覆盖旧版本。

生成接口在提交前检查图片数量、文件存在、重复引用和场景冲突，不再静默丢掉素材。前端编排后若服务类型、工作流或索引对应的素材名称已变化，后端要求重新编排。任务提交时固定 Provider 配置，之后修改设置不会改变已提交任务。生成记录区分计划时长、实际请求时长和像素预算来源；这些是请求参数，不能替代对成片尺寸和时长的实际测量。下载使用临时文件，完整且非空后再发布，失败不覆盖已有视频。

当前视频 Provider 尚未接入参考音频，因此画布不会把音色样本显示为可连入的视频素材。候选批次进度保存在作品 segments/.jobs 目录，完成记录可在重启后恢复查询；进行中的批次标记为中断，保留已有成功候选，不自动重复调用模型。重新生成会新增输出版本，保留之前成功的视频版本。

## 离线验证

服务设置按视频、文本、图片和音频分类编辑。草稿取消时可以放弃修改，保存只提交变化的字段。后端缓存配置快照，文件变化时重新读取，采用锁与临时文件替换避免并发覆盖或写入中断；显式清空密钥、地址或 LoRA 不会回填旧值。连接测试只检查地址，不保存设置、不提交生成任务。

画布和设置组件按需加载；视频进入可视范围后加载，缩放和平移不重复序列化所有节点内容。节点和输入连线使用索引查找，生成记录读取合并并发请求，并防止切换作品后旧响应覆盖当前作品。

```sh
python -m unittest dev.api.test_config_store dev.api.test_workflow_store -v
node --test dev/ui/test_service_settings.mjs dev/ui/test_workflow_graph.mjs dev/ui/test_workflow_video.mjs
python -m unittest dev.api.test_project_summary -v
node --test dev/ui/test_project_library.mjs
python -m unittest dev.api.test_video_contract -v
python -m unittest dev.api.test_video_controls -v
node --test dev/ui/test_video_settings.mjs
npm run build --prefix web
```

接口测试使用 FastAPI TestClient，通过 `requirements-dev.txt` 安装测试依赖。所有接口测试文件都写入临时目录，不调用模型、不修改用户作品。
